# 防災ゲーム「Protect Yourself」

Unityで楽天市場と連携した防災ゲームを5人で共同開発しました．

楽天市場から防災グッズを買い込んだ後に災害をシミュレーションし，被災地において購入した防災グッズで何日間生き残れるかをAIが計算してフィードバックをくれるゲームです．
